How It Works

1📤

Upload Image

Drag & drop or browse any JPEG, PNG, or WebP photo.

2📐

Preprocess

Resized to 224×224, normalized with ImageNet mean/std.

3🧠

3 Models Infer

MobileNetV2, ShuffleNetV2, and SqueezeNet each run a forward pass.

4✅

Consensus Logic

Majority-vote algorithm determines the final agreed prediction.

5📊

Results Displayed
